# Shabtzak App — מסמך עיצוב

**תאריך:** 2026-04-26  
**סטטוס:** מאושר לפיתוח

---

## 1. סקירה כללית

אפליקציית Web לניהול שיבוצים (שבצ"ק) ויציאות הביתה במחלקה צבאית. RTL בעברית בלבד. שני סוגי משתמשים: לוחמים (ללא כניסה) ומנהלים (Firebase Auth).

---

## 2. Stack טכנולוגי

| שכבה | טכנולוגיה |
|------|-----------|
| Frontend | Next.js 14 (Pages Router), React, TypeScript |
| Styling | Tailwind CSS, RTL גלובלי (`dir="rtl"`) |
| Backend / DB | Firebase Firestore (real-time `onSnapshot`) |
| Auth | Firebase Auth — 4 חשבונות מנהל נפרדים |
| ייצוא | `html2pdf.js` לPDF, `SheetJS (xlsx)` לExcel |
| פריסה | Netlify |

---

## 3. מבנה דפים (Routing)

```
/                      → בחירת זהות לוחם (רשימה נפתחת, ללא login)
/dashboard             → דשבורד לוחם (משימה הבאה + רשימה + יציאות)
/schedule              → שבצ"ק מחלקתי מלא (צפייה בלבד)
/leave/new             → הגשת בקשת יציאה

/admin/login           → כניסת מנהל
/admin/dashboard       → דשבורד מנהל (סיכום יום, כמה בבית)
/admin/schedule/new    → בניית שבצ"ק חדש
/admin/schedule/[id]   → עריכת שבצ"ק קיים
/admin/leave           → ניהול בקשות יציאה (אישור/דחייה)
/admin/justice         → טבלת צדק
```

## 5. ממשק לוחמים

### מסך בחירת זהות (`/`)
- רשימה נפתחת / חיפוש לפי שם מתוך `soldiers`
- בחירה → שמירה ב-`localStorage` → ניתוב ל-`/dashboard`

### דשבורד לוחם (`/dashboard`) — פריסה A (מאוחד)
- **כרטיס "המשימה הבאה"** בולט בראש המסך (כחול כהה), עם שם, שעות ושותפים
- **רשימת משימות השבוע** — כרטיסייה לכל משימה עם גבול ימני צבעוני לפי סוג
- **בקשות יציאה** — רשימה עם status badge (ממתין/מאושר/נדחה)
- **כפתור** "+ בקשת יציאה חדשה" → `/leave/new`
- **Real-time:** `onSnapshot` על `assignments` ו-`leave_requests` לפי `soldier_id`

### בקשת יציאה (`/leave/new`)
- תאריכון עם בחירת ימים
- Live counter: כמה כבר ביקשו לכל יום
- **התראת אזהרה** (לא חסימה) כשיום מגיע ל-8 בקשות: "⚠️ יום זה מלא — 8 חיילים ביקשו יציאה. הבקשה תישלח לאישור מיוחד."

## 6. ממשק מנהל

### בניית שבצ"ק (`/admin/schedule/new`) — פריסה A (כרטיסיות + רשימה)

**עמודה שמאל — משימות:**
- כרטיסיית משימה לכל slot (שם, שעות, חיילים משובצים)
- כפתור "+ הוסף משימה" → modal עם שדות: שם, סוג, שעת התחלה/סיום, כמות נדרשת
- גרירה והשלכה (Drag & Drop עם `@dnd-kit`) לשינוי סדר

**עמודה ימין — חיילים:**
- רשימת כל החיילים הפעילים
- ליד כל שם: dot צבעוני (ירוק=פנוי, כחול=בבית, כתום=משובץ)
- badge: מספר משימות + שעות מנוחה עד הבאה
- לחיצה על חייל → הוספתו למשימה הנבחרת

**כותרת עליונה:**
- טווח תאריכים הניתן לעריכה
- כפתור "⚠ בדוק שגיאות" → הרצת ולידציה
- כפתור "שמור טיוטה" / "פרסם"
- כפתור "ייצוא" (PDF / Excel)

### ניהול יציאות (`/admin/leave`)
- טבלה: שם חייל | תאריך | סטטוס | פעולה
- כפתורי אישור / דחייה לכל שורה
- **Live counter** לכל תאריך: "X/8 חיילים בבית"
- צבעים: ירוק (≤5), צהוב (6-7), אדום (8+)

---

## 7. מערכת ולידציה

מופעלת בלחיצה על "בדוק שגיאות" או בפרסום שבצ"ק. כל הבדיקות בצד הקליינט:

| בדיקה | תנאי | חומרה |
|-------|------|-------|
| שיבוץ כפול | חייל ב-2 משימות חופפות בזמן | 🔴 שגיאה |
| חוסר מנוחה | פחות מ-6 שעות בין סיום משימה לתחילת הבאה | 🟡 אזהרה |
| חלוקה לא שוויונית | הפרש >4 שעות בין החייל הטרוד ביותר לפחות טרוד | 🟡 אזהרה |
| משימה לא מלאה | שובצו פחות מ-`required_people_count` | 🔴 שגיאה |
| מכסת יציאות | ≥8 בקשות לאותו יום | ⚠️ התראה (לא חסימה) |

פרסום אפשרי גם עם שגיאות — לאחר popup: "ישנן X שגיאות. לפרסם בכל זאת?"

---

## 8. טבלת צדק (`/admin/justice`)

מחשבת **לכל חייל**, על **טווח תאריכים** שהמנהל בוחר:

| שם | שמירה (שעות) | פטרול (שעות) | מטבח (שעות) | לוגיסטיקה (שעות) | [כל סוג נוסף] | סה"כ שעות | סה"כ משימות |
|----|-------------|-------------|-------------|-----------------|--------------|-----------|-------------|

- עמודה נוצרת **דינמית** לפי סוגי המשימות הקיימים ב-`task_types`
- מיון לפי "סה"כ שעות" (גבוה → נמוך) לאיתור עומס
- צבע שורה: אדום = עומס יתר יחסית לממוצע, ירוק = מתחת לממוצע

---

## 9. ייצוא

- **PDF:** `html2pdf.js` — מייצר את תצוגת השבצ"ק כPDF
- **Excel:** `SheetJS (xlsx)` — גיליון עם עמודות: חייל | משימה | שעת התחלה | שעת סיום | סוג
- גם אם יש שגיאות פתוחות — ייצוא מותר לאחר אישור popup

---

## 10. Real-time & אבטחה

- **Firestore Rules:** כתיבה לכל collection — אדמין בלבד (מאומת). קריאה — ציבורית (לצפייה בשבצ"ק).
- **`leave_requests`:** גם לוחמים יכולים ליצור רשומות חדשות (write), אך לא לשנות status.
- **`onSnapshot`** על `tasks`, `assignments`, `leave_requests` — real-time לכל הדפים הרלוונטיים.

## 12. MVP — סדר עדיפויות

1. **ממשק לוחמים** — בחירת זהות, דשבורד, הגשת יציאה + התראת מכסה
2. **ממשק מנהל — ניהול יציאות** — אישור/דחייה, counter יומי
3. **בניית שבצ"ק** — יצירת משימות + שיבוץ חיילים
4. **מערכת ולידציה** — שיבוץ כפול + חוסר מנוחה + משימה לא מלאה
5. **טבלת צדק**
6. **ייצוא PDF + Excel**

# שבצק צוות אוראל — מסמך עיצוב מלא (גרסה 2)

**תאריך:** 2026-04-28
**סטטוס:** מאושר לפיתוח

---

## 1. סקירה כללית

אפליקציה לניהול שבצ"ק שוטף לצוות. חמישה מודולים:
1. ניהול כוח אדם (מצבה)
2. בניית שבצ"ק (מנהל)
3. צפייה בשבצ"ק (ציבורי)
4. יציאות — בקשות + אישור סופי
5. טבלת צדק

---

## 2. מבנה Routing

```
/                          → שבצ"ק ציבורי (רשת + סינון אישי)
/leave/request             → בקשת יציאות (רשת ימים לסימון עצמי)

/admin/login               → כניסת מנהל
/admin/soldiers            → ניהול כוח אדם (מצבה)
/admin/schedule/new        → בניית שבצ"ק חדש
/admin/schedule/[id]       → עריכת שבצ"ק קיים
/admin/leave               → יציאות סופי (אישור + עריכה)
/admin/justice             → טבלת צדק
```

## 3. מבנה נתונים — Firestore

### `soldiers/{id}` (מורחב)
```ts
{
  full_name: string
  is_commander: boolean       // true עבור 6 המפקדים
  is_active: boolean
  notes: string               // "שבוע-שבוע", "ראשון-שני" וכו'
  fixed_home_ranges: Array<{ from: string; to: string }>  // YYYY-MM-DD טווחים קבועים
  team: string
}
```

### `schedules/{id}` (ללא שינוי)
```ts
{
  name: string
  start_datetime: Timestamp
  end_datetime: Timestamp
  status: 'draft' | 'published'
  created_by: string
}
```

### `task_types/{id}` (מורחב)
```ts
{
  name: string
  difficulty: 'hard' | 'easy'
  color: string
  requires_commander: boolean   // האם נדרש מפקד
  soldiers_required: number     // כמה חיילים בכל משמרת
  shift_duration_hours: number  // אורך משמרת בשעות (2, 4, 8...)
  is_emphasized: boolean        // true עבור מטבח/רס"פ/של"ז בטבלת צדק
}
```

### `tasks/{id}` (ללא שינוי)
```ts
{
  schedule_id: string
  task_name: string
  task_type: string
  difficulty: 'hard' | 'easy'
  start_datetime: Timestamp
  end_datetime: Timestamp
  required_people_count: number
  requires_commander: boolean
  notes?: string
}
```

### `assignments/{id}` (ללא שינוי)
```ts
{
  task_id: string
  soldier_id: string
}
```

### `leave_requests/{id}` (מורחב)
```ts
{
  soldier_id: string
  date: string                  // YYYY-MM-DD
  status: 'pending' | 'approved' | 'rejected'
  is_final: boolean             // false = בקשה, true = יציאות סופי
  created_at: Timestamp
  reviewed_by?: string
}
```

## 4. מודול א — ניהול כוח אדם (`/admin/soldiers`)

### תצוגה
טבלה עם שורה לכל חייל:

| # | שם | מפקד | הערות | מגבלות קבועות | פעיל |
|---|----|----|------|---------------|------|
| 1 | אוראל אפנזר | ✓ | | | ✓ |
| 6 | עמיחי עוזיאל | ✓ | ראשון-שני | 26/4–2/5 בבית | ✓ |

### פעולות
- **עריכה inline**: לחיצה על שדה פותחת עריכה במקום
- **מגבלות קבועות**: כפתור "+ הוסף טווח" → תאריכון מ/עד → נשמר כ-`fixed_home_ranges`
- **הוסף חייל**: כפתור בתחתית הטבלה
- **הפעל/השבת**: toggle בעמודה פעיל

### מפקדים (is_commander = true)
אוראל אפנזר, יהונתן בוצר, דביר משה, אופיר אלטמן, רפאל אלקיים, עמיחי עוזיאל

## 5. מודול ב — בניית שבצ"ק (`/admin/schedule/[id]`)

### שלב א — הגדרת שם וטווח תאריכים
- שם השבצ"ק
- תאריך התחלה / סיום
- שעת חילופים: ברירת מחדל **10:00** (ניתנת לשינוי)

### שלב ב — הגדרת סוגי משימות לשבצ"ק זה
כפתור "+ הוסף סוג משימה" → מודאל:
- שם המשימה (פילבוקס, כיתת כוננות, מוצב, מטבח...)
- צבע
- כמה חיילים נדרשים
- האם נדרש מפקד ✓/✗
- אורך משמרת בשעות (2 / 4 / 8 / מותאם)
- קל/קשה

### שלב ג — מילוי הרשת

**מבנה הרשת:**
- **שורות** = חלונות זמן (נגזרים אוטומטית מטווח + אורך משמרת)
- **עמודות** = המשימות שהוגדרו
- **עמודות עזר** (נראות רק בבנייה, לא בפרסום):
  - יוצאים — מי עוזב לבית בשורה זו (לפי יציאות סופי)
  - חוזרים — מי חוזר מבית בשורה זו
  - נוכחים — מי נוכח לאחר החלפה

**שורת חילופים (10:00):**
- מודגשת בצהוב
- מציגה אוטומטית: "יוצאים: X, חוזרים: Y"
- המערכת מתריעה אם לא שובצו החוזרים

**כל תא בטבלה:**
- שמות החיילים המשובצים (chips)
- אינדיקטור: ✓ מלא / ⚠ חסר (מספר שחסרים)
- לחיצה → חלונית צד: רשימת חיילים זמינים לשיבוץ

**חלונית צד — חיילים זמינים:**
- מסנן אוטומטית:
  - ✗ חיילים בבית (לפי יציאות סופי + מגבלות קבועות)
  - ✗ חיילים במשימה חופפת
- מציג לכל חייל: שעות מנוחה מהמשמרת הקודמת
- dot: 🟢 פנוי | 🔴 בבית | 🟡 פחות מ-8 שעות מנוחה
- אם המשימה דורשת מפקד — מפקדים מופיעים ראשונים עם תג "מפקד"

### ולידציה (כפתור "בדוק שגיאות" + בפרסום)

| שגיאה | תנאי | חומרה |
|-------|------|-------|
| שיבוץ בזמן בית | חייל משובץ ביום שהוא בבית לפי יציאות סופי | 🔴 |
| שיבוץ בזמן מגבלה קבועה | חייל משובץ בטווח קבוע שהוגדר | 🔴 |
| אין מפקד | משימה שדורשת מפקד ואין אחד משובץ | 🔴 |
| משימה לא מלאה | פחות חיילים מהנדרש | 🔴 |
| שיבוץ כפול | חייל בשתי משימות חופפות | 🔴 |
| מנוחה קצרה | פחות מ-8 שעות בין סיום לתחילת משמרת הבאה | 🟡 |
| חוזר לא משובץ | חייל חוזר מבית ב-10:00 ולא משובץ לאף משימה באותו יום | 🟡 |
| חלוקה לא שוויונית | הפרש >4 שעות בין החייל הטרוד לפחות טרוד | 🟡 |

פרסום אפשרי גם עם שגיאות — לאחר popup: "ישנן X שגיאות. לפרסם בכל זאת?"

## 6. מודול ג — שבצ"ק ציבורי (`/`)

### תצוגה
רשת זהה לבנייה, **ללא** עמודות עזר.

**כותרת:**
- שם השבצ"ק + טווח תאריכים
- ניווט ← → בין שבצ"קים (לשבצ"ק שוטף)
- selector: בחירת חייל (חיפוש עברי)

**ברירת מחדל (ללא סינון):**
- כל המשימות מוצגות ברשת
- כל חייל מוצג כ-chip עם שם מלא

**עם חייל נבחר:**
- שורות שהחייל משובץ בהן → רקע navy
- שמו של החייל הנבחר → chip מודגש (לבן על navy)
- שורות ללא שיבוץ → אפור

**כפתור "המשמרות שלי":**
- מסנן לתצוגת C — רשימה אנכית של המשמרות האישיות בלבד
- כל כרטיסייה: שם משימה, שעות, שותפים

## 7. מודול ד — יציאות

### שלב א — בקשות (`/leave/request`)

**תצוגה לחייל:**
- חייל בוחר שמו בראש הדף
- רשת: שורות = חיילים, עמודות = ימים (14 הימים הקרובים)
- לחיצה על תא = toggle בקשה לאותו יום
- **כללים** (מוצגים כהנחיות, לא חסימה):
  - עד 5 ימים בשבועיים
  - שישי אחד + שבת אחת לכל היותר
  - מומלץ ימים ברצף
- **Counter חי** מתחת לכל עמודה: "X ביקשו" — צבע ירוק (≤5) / צהוב (6-7) / אדום (8+)

### שלב ב — יציאות סופי (`/admin/leave`)

**תצוגה:**
- רשת זהה לבקשות
- תאים: לבן (לא ביקש) / כחול (ביקש, ממתין) / ירוק (אושר) / אפור (נדחה)
- מנהל לוחץ על תא → toggle אישור/דחייה
- **שורת מצבה** בתחתית: כמה נוכחים בכל יום
- **שורת סה"כ בבית**: counter לכל עמודה

כפתור "פרסם יציאות" → הופך is_final=true → מזין את עמודות העזר בשבצ"ק

## 8. מודול ה — טבלת צדק (`/admin/justice`)

### מבנה
- **שורות** = חיילים (ממוינים לפי עומס יורד)
- **עמודות** = כל סוגי המשימות הקיימות (דינמי לפי task_types)
- **הדגשה**: עמודות מטבח / רס"פ / של"ז עם רקע כחול בהיר
- **עמודת סה"כ שעות** + **עמודת סה"כ משמרות**

### צבע שורות
- 🔴 אדום: מעל ממוצע + 20%
- 🟢 ירוק: מתחת לממוצע − 20%
- לבן: ביטחון

### סינון
- בחירת טווח תאריכים (ברירת מחדל: השבצ"ק הנוכחי)
- הצג: כולם / מפקדים בלבד / לוחמים בלבד

## 10. סדר עדיפויות MVP

1. **ניהול כוח אדם** — מפקדים + מגבלות
2. **יציאות** — רשת בקשות + אישור מנהל
3. **בניית שבצ"ק** — הגדרת משימות + מילוי רשת
4. **ולידציה** — שיבוץ בזמן בית + מפקד חסר
5. **שבצ"ק ציבורי** — רשת + סינון אישי
6. **טבלת צדק** — כל משימות + הדגשת קלות
